.booleanTrue or false. It is not the same as 1 or 0.true  false

Arithmetic and comparison

1 + 2            rem 3
1 + 2.5          rem 3.5
7 / 2            rem 3.5
6 / 2 type       rem .real
7 // 2           rem 3
-7 // 2          rem -4
7 mod 2          rem 1
1 equal 1.0      rem true
1 equal "1"      rem false
1 + "1"          rem error
true + 1         rem error

An integer mixed with a real gives a real. / always gives a real; // rounds down, as in Python. Text, booleans and numbers do not mix.

Checking and converting

42 type          rem .integer
42 is .integer   rem true
42 is .real      rem false
X = 1
X = 2            rem ok
X = 2.5          rem error: X is .integer
X = "a"          rem error: X is .integer

Rank is statically typed. A variable keeps the type of its first value, and values are never converted automatically. To change a type, convert explicitly: "42" integer, 42 text.

Same type: .array .sequence

A = array 10 20 30
A 0              rem 10
A type           rem .array
M = array shape 2 3 fill 0

S = 1 to 5
S type           rem .sequence
N = 1 to #
N take 4         rem 1 2 3 4

An array holds elements that all have the same type. A matrix or a tensor is just an array with more axes. Indexing starts at 0.

A sequence produces its items only when they are needed, so it can be endless: 1 to # has no last item. Take a few items; sum of an endless sequence is an error.

Mixing types is an error: array 1 2.0 fails. Write array 1.0 2.0 to get real values.

Mixed types: .tuple .record

Pair = tuple 42 "Ada"
Pair 0           rem 42
unpack Id Name = Pair

Person = record
  .name = "Ada"
  .age = 36
end
Person .age = 37

A tuple keeps a fixed number of positions, and each position can have a different type. You cannot assign to a position after the tuple is created.

A record keeps named fields. You can change a field value, but the field names and their types stay the same.

Records are shared by reference, so a change is visible everywhere the record is used. Arrays behave like plain values and are copied.
