# Rank demo library

Rank examples from programming contests, numerical exercises and data-analysis projects. Each collection links to its original source; `.ra` files contain examples and `_test.ra` files contain checks.

## Folders

- [Advent of Code](aoc/) — Programming puzzles from [Advent of Code](https://adventofcode.com/), grouped by year.
- [AtCoder](atcoder/) — Programming-contest exercises from [AtCoder](https://atcoder.jp/).
- [MATLAB Cody](cody/) — Array, numerical and simulation exercises based on [MATLAB Cody](https://www.mathworks.com/matlabcentral/cody/problems.html), with Rank-specific contracts and tests.
- [CSES Problem Set](cses/) — Algorithm exercises from the [CSES Problem Set](https://cses.fi/problemset/), grouped by topic.
- [Deep-ML](deepml/) — Linear algebra, statistics and machine-learning exercises from [Deep-ML](https://www.deep-ml.com/).
- [Dyalog Programming Competition](dyalog/) — Rank solutions to programming-competition tasks from [Dyalog](https://www.dyalog.com/), grouped by year.
- [Project Euler](euler/) — Mathematical programming problems from [Project Euler](https://projecteuler.net/). Individual examples link to the original problem.
- [Kaggle](kaggle/) — Data-analysis and modelling examples based on [Kaggle competitions](https://www.kaggle.com/competitions). Individual examples name the competition and required datasets.
- [LeetCode](leetcode/) — Programming interview and algorithm exercises from [LeetCode](https://leetcode.com/problemset/).
- [PostgreSQL Exercises](pgexercises/) — Database-query exercises from [PostgreSQL Exercises](https://pgexercises.com/), adapted to Rank and a local SQLite copy of the club dataset.
- [Data Structures and Value Semantics](structures/) — Examples developed in this repository for record aggregation, structural sharing and Rank value semantics; see the [language documentation](../../docs/language/values-addressing.md).
- [TidyTuesday](tidytuesday/) — Data-analysis examples based on the weekly datasets from [TidyTuesday](https://github.com/rfordatascience/tidytuesday).
- [TPC-H](tpch/) — Database-query examples based on the [TPC-H benchmark specification](https://www.tpc.org/tpc_documents_current_versions/pdf/tpc-h_v3.0.1.pdf), using a local SQLite dataset.
