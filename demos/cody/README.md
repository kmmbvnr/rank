# MATLAB Cody scenarios

[MATLAB Cody](https://www.mathworks.com/matlabcentral/cody/problems.html) is a
collection of small MATLAB programming problems. Its scoring rewards short
solutions, so these demos do not copy its tests or optimize for one-liners.

Each file here takes a Cody scenario as a starting point, then gives it a
Rank-owned contract, inputs, and oracle tests. The aim is to find useful array,
numerical, and simulation problems that expose a general Rank capability.
