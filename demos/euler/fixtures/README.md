# Euler input files

`0054_poker.txt` is the unmodified [official input for Poker Hands](https://projecteuler.net/resources/documents/0054_poker.txt): 1,000 deals, ten cards per line. See [Project Euler 54](https://projecteuler.net/problem=54) for the rules.

`0059_cipher.txt` is the unmodified [official input for XOR Decryption](https://projecteuler.net/resources/documents/0059_cipher.txt): 1,455 comma-separated ASCII codes. See [Project Euler 59](https://projecteuler.net/problem=59).
