# Euler input files

`0054_poker.txt` is the unmodified [official input for Poker Hands](https://projecteuler.net/resources/documents/0054_poker.txt): 1,000 deals, ten cards per line. See [Project Euler 54](https://projecteuler.net/problem=54) for the rules.

`0059_cipher.txt` is the unmodified [official input for XOR Decryption](https://projecteuler.net/resources/documents/0059_cipher.txt): 1,455 comma-separated ASCII codes. See [Project Euler 59](https://projecteuler.net/problem=59).

`0067_triangle.txt` is the unmodified [official input for Maximum Path Sum II](https://projecteuler.net/resources/documents/0067_triangle.txt): a triangle of one hundred rows. See [Project Euler 67](https://projecteuler.net/problem=67).

`0079_keylog.txt` is the unmodified [official input for Passcode Derivation](https://projecteuler.net/resources/documents/0079_keylog.txt): fifty successful login attempts of three digits each. See [Project Euler 79](https://projecteuler.net/problem=79).

`0081_matrix.txt` is the unmodified [official input for Path Sum: Two Ways](https://projecteuler.net/resources/documents/0081_matrix.txt): an 80 by 80 matrix, one comma-separated row per line. Problems [82](https://projecteuler.net/problem=82) and [83](https://projecteuler.net/problem=83) use the same matrix.

`0089_roman.txt` is the unmodified [official input for Roman Numerals](https://projecteuler.net/resources/documents/0089_roman.txt): one thousand numerals, one per line. See [Project Euler 89](https://projecteuler.net/problem=89).

`0096_sudoku.txt` is the unmodified [official input for Su Doku](https://projecteuler.net/resources/documents/0096_sudoku.txt): fifty puzzles, each a `Grid NN` line followed by nine rows of nine digits (0 for an empty cell). See [Project Euler 96](https://projecteuler.net/problem=96).

`0098_words.txt` is the unmodified [official input for Anagramic Squares](https://projecteuler.net/resources/documents/0098_words.txt): about 1,800 quoted, comma-separated English words. See [Project Euler 98](https://projecteuler.net/problem=98).

`0099_base_exp.txt` is the unmodified [official input for Largest Exponential](https://projecteuler.net/resources/documents/0099_base_exp.txt): one thousand `base,exponent` pairs, one per line. See [Project Euler 99](https://projecteuler.net/problem=99).

`0102_triangles.txt` is the unmodified [official input for Triangle Containment](https://projecteuler.net/resources/documents/0102_triangles.txt): one thousand triangles, six comma-separated coordinates per line. See [Project Euler 102](https://projecteuler.net/problem=102).

`0105_sets.txt` is the unmodified [official input for Special Subset Sums: Testing](https://projecteuler.net/resources/documents/0105_sets.txt): one hundred sets of seven to twelve positive integers, one set per line. See [Project Euler 105](https://projecteuler.net/problem=105).

`0107_network.txt` is the unmodified [official input for Minimal Network](https://projecteuler.net/resources/documents/0107_network.txt): a 40 by 40 symmetric weight matrix, one comma-separated row per line, with `-` for no link. See [Project Euler 107](https://projecteuler.net/problem=107).
