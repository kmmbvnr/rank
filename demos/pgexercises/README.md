# PostgreSQL Exercises

Database-query exercises from [PostgreSQL Exercises](https://pgexercises.com/), adapted to Rank and a local SQLite copy of the club dataset.

## Folders

- [Aggregation](aggregates/) — Grouping and aggregation exercises from [PostgreSQL Exercises](https://pgexercises.com/questions/aggregates/).
- [Basic Queries](basic/) — Basic filtering and selection exercises from [PostgreSQL Exercises](https://pgexercises.com/questions/basic/).
- [Date and Time](date/) — Date and time exercises from [PostgreSQL Exercises](https://pgexercises.com/questions/date/).
- [Joins and Subqueries](joins/) — Joins and subquery exercises from [PostgreSQL Exercises](https://pgexercises.com/questions/joins/).
- [Recursive Queries](recursive/) — Recursive-query exercises from [PostgreSQL Exercises](https://pgexercises.com/questions/recursive/).
- [String Operations](string/) — Text-processing exercises from [PostgreSQL Exercises](https://pgexercises.com/questions/string/).
- [Modifying Data](updates/) — Data modification exercises from [PostgreSQL Exercises](https://pgexercises.com/questions/updates/).
