# Dyalog Programming Competition

Rank solutions to programming-competition tasks from [Dyalog](https://www.dyalog.com/), grouped by year.

## Folders

- [Dyalog Programming Competition 2010](2010/) — Rank solutions to the 2010 programming competition from [Dyalog](https://www.dyalog.com/), including the buy-or-rent model and its XML input.
- [Dyalog Programming Competition 2011](2011/) — Rank examples based on tasks from the 2011 programming competition from [Dyalog](https://www.dyalog.com/).
